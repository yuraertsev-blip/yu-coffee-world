# Ю кофе — маленький мир

[Открыть кофейню](https://yuraertsev-blip.github.io/yu-coffee-world/)

3D-прогулка по кофейне на Розваже, 13, по фотографиям и видео владельца. Приближённая реконструкция с оценочными размерами.

## Версия 0.7

Бариста используют полноценную VRM-модель со скелетом, деформируемой кожей, пальцами, морганием и физикой волос. Три варианта одежды и цвета вдохновлены фотографиями: цветочный ободок, тёмный фартук, розовое кимоно. Базовое лицо общее: это стилизованные персонажи, а не точные портретные копии.

Нажмите на персонажа или метку над головой: «другой Бариста» переключает образ, «заказать кофе» запускает приготовление капучино. Между заказами бариста перемещается по рабочим станциям. 36 рисунков латте-арта перемешиваются без повторов в пределах колоды. Готовую чашку можно рассмотреть, все рисунки доступны в галерее.

## Управление

Обзор — перетаскивание и масштаб. Внутри — WASD/стрелки, Shift для ускорения, мышь для обзора, Esc освобождает курсор. На телефоне доступны экранные кнопки. «За стойкой» открывает дополнительные ракурсы. «Фото и меню» показывает референсы.

## Разработка и публикация

Node.js 22.12+:

```sh
npm ci
npm run dev
npm test
npm run build
```

Локальный адрес: http://127.0.0.1:5186/. GitHub Actions запускает тесты и публикует `dist` в GitHub Pages после push в main. `vite.config.js` задаёт путь `/yu-coffee-world/` для Actions. Все runtime-ресурсы хранятся в `public`; внешние серверы моделей не нужны.

Сцена: `src/scene.js`, оборудование: `src/bar.js`, персонажи: `src/baristas.js` и `src/barista-outfits.js`, заказы: `src/coffee-service.js`, рисунки: `src/latte-art.js`.

## Ограничения

Скрытые поверхности и окружение упрощены. Персонажи стилизованы; одежда адаптирована к общей базовой модели. Заказы не сохраняются между перезагрузками; выбранный образ сохраняется в браузере. На физическом iPhone производительность пока не проверена. На узких экранах отключено экранное затенение для снижения нагрузки.

## Лицензии

Сторонняя основа персонажей: pixiv Inc., подробности и условия — [THIRD_PARTY.md](THIRD_PARTY.md). Фотографии интерьера и художественные материалы не предоставляются под свободной лицензией.

## Игровая комната

Коробки на столиках в зале и кнопка «Игры» открывают отдельный экран. Доступны УНО, подкидной дурак, шашки, техасский холдем и «Поймай круассан». Правила мини-версий указаны в меню. Раздача автоматическая, 1–4 компьютерных соперника (в шашках один, в аркаде до трёх); каждой новой партии присваиваются случайные русские имена. Покер использует только игровые фишки и фиксированные небольшие ставки.

«В кофейню» и Escape приостанавливают партию и возвращают в сцену. Повторное открытие продолжает партию; перезагрузка страницы сбрасывает её. Во время игры 3D-рендер приостановлен для экономии ресурсов. «Выбрать игру» или «Новая партия» начинают новую игру.

Добавление игры: определение в `src/games/registry.js`, отдельный движок с действиями в `src/games/`, представление в `src/games/ui.js`. Коробки и меню формируются из реестра. Тесты прогоняют партии ботов, контроль колод, обязательные взятия, покерные комбинации и банк, таймер аркады.
