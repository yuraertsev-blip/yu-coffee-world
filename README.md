# Ю кофе — маленький мир

[Открыть кофейню](https://yuraertsev-blip.github.io/yu-coffee-world/)

3D-прогулка по кофейне на Розваже, 13, по фотографиям и видео владельца. Приближённая реконструкция с оценочными размерами.

## Версия 0.7

Бариста используют полноценную VRM-модель со скелетом, деформируемой кожей, пальцами, морганием и физикой волос. Три варианта одежды и цвета вдохновлены фотографиями: цветочный ободок, тёмный фартук, розовое кимоно. Базовое лицо общее: это стилизованные персонажи, а не точные портретные копии.

Нажмите на персонажа или метку над головой: «другой Бариста» переключает образ, «заказать кофе» запускает приготовление капучино. Между заказами бариста перемещается по рабочим станциям. 36 рисунков латте-арта перемешиваются без повторов в пределах колоды. Готовую чашку можно рассмотреть, все рисунки доступны в галерее.

## Управление

Обзор — перетаскивание и масштаб. Внутри — WASD/стрелки, Shift для ускорения, мышь для обзора, Esc освобождает курсор. На телефоне доступны экранные кнопки. «За стойкой» открывает дополнительные ракурсы. «Фото и меню» показывает референсы.

## Разработка и публикация

Node.js 22.12+:

```sh
npm ci
npm run dev
npm test
npm run build
```

Локальный адрес: http://127.0.0.1:5186/. GitHub Actions запускает тесты и публикует `dist` в GitHub Pages после push в main. `vite.config.js` задаёт путь `/yu-coffee-world/` для Actions. Все runtime-ресурсы хранятся в `public`; внешние серверы моделей не нужны.

Сцена: `src/scene.js`, оборудование: `src/bar.js`, персонажи: `src/baristas.js` и `src/barista-outfits.js`, заказы: `src/coffee-service.js`, рисунки: `src/latte-art.js`.

## Ограничения

Скрытые поверхности и окружение упрощены. Персонажи стилизованы; одежда адаптирована к общей базовой модели. Заказы не сохраняются между перезагрузками; выбранный образ сохраняется в браузере. На физическом iPhone производительность пока не проверена. На узких экранах отключено экранное затенение для снижения нагрузки.

## Лицензии

Сторонняя основа персонажей: pixiv Inc., подробности и условия — [THIRD_PARTY.md](THIRD_PARTY.md). Фотографии интерьера и художественные материалы не предоставляются под свободной лицензией.

## Игровая комната

Коробки на столиках в зале и кнопка «Игры» открывают отдельный экран. Доступны УНО, подкидной дурак, шашки, техасский холдем и «Поймай круассан». Правила мини-версий указаны в меню. Раздача автоматическая, 1–4 компьютерных соперника (в шашках один, в аркаде до трёх); каждой новой партии присваиваются случайные русские имена. Покер использует только игровые фишки и фиксированные небольшие ставки.

«В кофейню» и Escape приостанавливают партию и возвращают в сцену. Повторное открытие продолжает партию; перезагрузка страницы сбрасывает её. Во время игры 3D-рендер приостановлен для экономии ресурсов. «Выбрать игру» или «Новая партия» начинают новую игру.

Добавление игры: определение в `src/games/registry.js`, отдельный движок с действиями в `src/games/`, представление в `src/games/ui.js`. Коробки и меню формируются из реестра. Тесты прогоняют партии ботов, контроль колод, обязательные взятия, покерные комбинации и банк, таймер аркады.


## Онлайн-зал и игры вдвоём

Гости автоматически подключаются к общему залу, выбирают имя и приглашают друг друга в любую из пяти игр. Первый другой гость сидит у столика; остальные стоят в очереди у входа. Онлайн-партии ведёт сервер: он проверяет участника и очередь хода, раздаёт карты и отдаёт каждому только собственную руку. Доска шашек разворачивается к игроку. В аркаде у каждого свой круассан, общий таймер и таблица счёта; боты отсутствуют.

«В кофейню» скрывает игру, но не останавливает совместную партию. Вернуться можно через «Игры» или список гостей. «Завершить совместную партию» освобождает обоих игроков. Приглашение действует 30 секунд. После 35 секунд отсутствия связи гость удаляется и его партия завершается; короткий разрыв или перезагрузка страницы сохраняет сеанс. Имена — свободные псевдонимы, не подтверждённые аккаунты.

### Локальная проверка

Запустите `npm run server` и `npm run dev` в разных терминалах. Откройте два независимых окна/вкладки на порту 5186. Vite направляет `/api` на локальный сервер 5187. Локальный сервер хранит зал в памяти и при перезапуске очищает его.

### Vercel и PostgreSQL

`api/[route].js` обслуживает join/state/command. Подключите отдельную Neon Postgres через Vercel Storage (Production). Секрет `DATABASE_URL` или `POSTGRES_URL` задаётся интеграцией, никогда не добавляется в клиент или GitHub. Таблица `yu_cafe_online` создаётся автоматически. Каждая операция проходит через транзакцию PostgreSQL с блокировкой строки, поэтому параллельные вызовы функций не теряют ходы. Игровые правила и закрытые колоды сохраняются между вызовами. Эта первая версия рассчитана на небольшой зал (до 100 сеансов); обновление раз в секунду, для аркады — чаще. Для большой нагрузки потребуется разделить хранение по залам/партиям и перейти на push-транспорт.

На Vercel клиент использует собственный `/api`. Для GitHub Pages задайте `VITE_ONLINE_URL` при сборке — публичный адрес проекта Vercel, без секрета. `ALLOWED_ORIGINS` ограничивает разрешённые сайты. По умолчанию разрешён текущий GitHub Pages origin. Без подключённого backend опубликованный клиент показывает сообщение о подготовке онлайн-зала, одиночные игры работают.

Проверки: `npm test` включает два HTTP-сеанса, скрытие колод, отклонение чужих/повторных ходов, приглашения, отключение, аркаду и завершение четырёх настольных игр с сериализацией после каждого хода.

## Музыкальная комната

Дарбука на правой стене над диваном и кнопка «Музыка» открывают выбор инструмента: укулеле, дарбука, мини-ударная установка, ханг (хендпан), бас-гитара, диджириду и большой рамочный барабан. У каждого есть три пресета и настройки громкости, яркости, эха, строя и длины звука (у диджириду — послезвучия).

Играйте мышью, касаниями или клавишами A–L и Q–Y, указанными на площадках. Диджириду звучит, пока удерживается площадка или клавиша. Громкость, яркость и эхо меняются во время игры; строй также меняет уже звучащий дрон. Звучание основано на живых записях инструментов: WAV-сэмплы загружаются при выборе инструмента и воспроизводятся через Web Audio. Для повторных ударов чередуются разные записи, Shift усиливает акцент. Добавлены комнатная реверберация и ограничение пиков. Источники и лицензии доступны в музыкальном окне и THIRD_PARTY.md. Выход, смена инструмента и потеря фокуса останавливают звук. Музыка не передаётся другим гостям.

## Осень и образы гостей

Осенние кроны и опавшая листва дополняют улицу. Внутри — тёплое приглушённое освещение; настолки находятся только на левом столике, справа горит свеча в круглой стеклянной чаше. Листья комнатных растений имеют изгиб, прожилки и микрорельеф.

Откройте «Гости» → «Имя и образ»: доступны 5 женских, 5 мужских образов и 5 животных (лиса, кот, заяц, медведь, енот). Портреты отрисованы из тех же моделей, которые видят другие гости. Используется общий файл модели бариста, без 15 дополнительных VRM-загрузок. Выбор сохраняется на сервере вместе с именем и в браузере для следующего посещения. API join и команда name принимают поле avatar; сервер разрешает только идентификаторы из guest-profiles.js, старые клиенты и сеансы получают образ по умолчанию.

У хендпана 15 нот в си миноре, с настройкой по измеренной основной частоте. У укулеле — 15 нот и переключатель «Ноты / Аккорды» (28 аккордов, четыре струны с коротким перебором). У баса — 15 нот, у диджириду — 8. Дарбука дополнена роллами пальцами по краю на 4 и 8 быстрых ударов; удары TEK/KA чередуются с интервалом 38 мс.

Хендпан отображается как круглый инструмент с центральным басом и 14 полями вокруг. Ударная установка имеет 11 одинаковых круглых кнопок в раскладке сверху, включая третий низкий том, открытый хэт, чайну, ковбэл и райд; закрытие хэта глушит открытый. У рамочного барабана 10 приёмов: четыре исходных, щелчок пальцев, сухой край, двойной бас, флэм и роллы ×4/×8. Дудук — 13 хроматических нот Ля3–Ля4, удержание ноты, мягкое дыхание, три пресета. Все 28 аккордов укулеле доступны с клавиатуры (клавиша подписана на каждой кнопке).

Музыкальные площадки поддерживают несколько независимых касаний. На дудуке и диджириду скольжение плавно меняет высоту удерживаемого звука; второй палец добавляет отдельный голос. На ханге и ударных вход на следующую площадку запускает новый удар, сохраняя затухание предыдущего. Можно одновременно играть несколько нот или ударов.

### Чайная карта

Нажатие на чайные упаковки на стойке или холодильнике и кнопка «Чаи» открывают карту. Есть поиск по названию/аромату, пять типов чая, отдельные карточки и пересчёт веса заварки для 250/500/750 мл. Первая редакция содержит 20 позиций, прочитанных по IMG_3985; ассортимент и частично закрытые названия ожидают корректировки владельца. Цены не перенесены. Все карточки используют окна одной оптимизированной фотографии реальной витрины, загружаемой при открытии карты. Данные находятся в `src/tea-catalog.js`. Рецепты относятся к настаиванию, не гонфу-проливам; это ориентиры по группам чая, а не проверенные рецепты конкретных партий.
